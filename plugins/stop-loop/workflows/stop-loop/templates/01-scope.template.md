## 기능맵에서 읽은 것 (기능맵이 입력에 있을 때만)

입력에 `docs/기능맵.md` 가 있을 때만 쓴다. 읽은 기능 ID 와 따라간 관련 기능의 기록이다 — 카드 머리말 `기능:` 의 ID 에서 그 「관련 기능」을 한 단계 따라간다.
짝(`짝:`) 구현은 코드 위치를 `01-scope.json` 의 `impactAreas` 에 넣고 아래 마지막 칸에 그 영역 이름을 적는다.

| 읽은 기능 ID | 어디서 왔나(카드 · 관련 기능 종류) | 코드 위치 | 영향 영역 판정에 넣은 곳 |
|---|---|---|---|
| {F-000} | {카드 · 짝:F-000 …} | {path} | {impactAreas 의 영역} |
