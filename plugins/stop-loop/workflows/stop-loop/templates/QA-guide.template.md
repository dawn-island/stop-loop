# 기능 항목 검증 칸

기능 단위 문서(설정 `unit.docPath` 가 가리키는, 기능마다 동작을 적는 문서)의 기능
항목마다, 기존 칸(설명·「코드 위치」·「이것이 없으면」) 뒤에 아래 세 칸을 더 적는다.
05 설계가 **건드린 기능의 칸만** 채운다 — 옛 항목을 한꺼번에 메우지 않는다.

## 기능 항목 검증 칸

- **사용자 진입 경로**: {이 기능에 들어가는 길 전부를 나열한다 — 메뉴·URL·명령 등
  하나가 아니라 있는 만큼}
- **조작 절차와 관찰할 결과**: {무엇을 누르거나 입력하고, 무엇이 보이면 맞는가}
- **함정**: {헷갈리기 쉬운 곳 — 비슷해 보이지만 다른 경로, 캐시, 순서 의존 등}

예시:

```
### F12. 이름 바꾸기

기존 기능 설명…
코드 위치: `src/x.ts`
*이것이 없으면*: …

- 사용자 진입 경로: 설정 화면 → 프로필 → 「이름 바꾸기」 / `/settings/profile`
- 조작 절차와 관찰할 결과: 새 이름을 입력하고 저장을 누르면, 화면 위 이름표가
  즉시 바뀌고 새로고침해도 남는다.
- 함정: 저장 버튼이 두 곳(모바일 헤더·데스크톱 사이드바)에 있고 모양이 다르다.
```
