## 설계 경고 신호

신호마다 한 줄: 해당 여부와 근거(05 설계의 자리나 코드 경로). 해당해도 그것만으로 반려하지
않는다 — 반려 기준은 「발견」 절 아래 문장과 같다(기록 32). 반려 기준에 못 미치면 「선택 사항」에
적는다. 반려할 때는 새 갈래를 만들지 않고 기존 갈래 「최소」로 적는다.

| 신호 | 해당하는가 | 근거(05 설계의 자리나 코드 경로) |
|---|---|---|
| 얕은 모듈 (겉면은 넓은데 감추는 것이 적다. 호출하는 쪽이 한 일을 하려고 여러 메서드를 엮어야 한다) | | |
| 정보 누출 (같은 내부 결정이 여러 곳에 있어 바꾸려면 여러 곳을 함께 고쳐야 한다) | | |
| 시간 순 분해 (아는 것이 아니라 실행 순서로 나눠 같은 표현과 불변식이 경계마다 되풀이된다) | | |
| 넘기기만 하는 메서드 (같은 인자를 같은 모양으로 다른 메서드에 넘길 뿐 감추는 것이 없다) | | |
