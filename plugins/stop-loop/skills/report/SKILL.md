# report — 워크플로우 몫을 이슈로 올린다

이 스킬은 실행 파일을 부르고 결과를 사람 말로 옮길 뿐이다. 판단(회사 정보 검사·같은 이슈 찾기)은 실행 파일이 한다.
러너가 PR 을 연 가지(`loop/<카드>`)에서, 프로젝트 뿌리에서 부른다. 먼저 확인 인자 없이 부른다(아무것도 올리지 않는다):

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/report_workflow.py" .
```

## 결과를 알려 줄 때

- 찍힌 「올릴 문장」·「댓글을 단다 #번호」·「올리지 않는다 — …」 줄을 **그대로** 사람에게 보여 준다. 고쳐 쓰지 않는다.
- 사람이 그 문장을 확인했을 때만 `--올리기` 를 붙여 다시 부른다. 확인이 없으면 다시 부르지 않는다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/report_workflow.py" . --올리기
```

- 「올리지 않는다」 줄은 회사 정보가 걸린 자리다. 올라가지 않았다고 알리고, 사람이 PR 본문의 그 칸을 고친 뒤 다시 돌린다.
- 「용어 절 없음」 줄이 있으면 그 검사는 건너뛰었다고 알린다.
- 실패하면 이유를 그대로 전한다.

## 하지 않는 것

- 확인 없이 `--올리기` 를 붙이지 않는다.
- 커밋하지 않는다. 카드 끝에 이슈 주소 한 줄이 더해지면 `git diff` 로 확인하고 커밋은 사람이 한다.
- 걸린 문장을 지우거나 바꿔 올리지 않는다.
