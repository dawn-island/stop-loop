# loop — 카드 하나를 러너로 돌린다

이 스킬은 러너를 부르고 결과를 사람 말로 옮길 뿐이다. 판단은 러너가 한다.
카드는 이 프로젝트의 `docs/backlog/` 에 있다. 카드 이름을 받아 파일을 찾는다.

먼저 무엇이 돌지 보여 준다(아무것도 바꾸지 않는다):

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/runner.py" . docs/backlog/<카드>.md --dry-run
```

열세 줄이 찍히면 실행한다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/runner.py" . docs/backlog/<카드>.md
```

앞 실행이 멈춘 카드를 이어받으려면 `--resume` 을 붙인다.

## 결과를 알려 줄 때

- 러너는 이 프로젝트 옆에 카드마다 작업 폴더(`<프로젝트>.<카드이름>`)를 열고 가지 `loop/<카드이름>` 에서 일한다.
- 단계별 산출물은 그 작업 폴더의 `.workflow/<카드이름>-<날짜>/` 에 쌓인다. 끝나면 이력에 남고 폴더는 치운다.
- 어떤 일이 있었는지는 `git log --grep='Loop-Issue: <카드이름>'` 로 본다.
- 러너 설정은 프로젝트 뿌리의 `stop-loop.config.json` 이다. 없으면 기본값으로 돈다.

## 하지 않는 것

- **승격**(카드의 `상태:` 를 아이디어에서 대기로 올리기)은 하지 않는다 — 사람이 그 줄을 고친다.
- **병합**은 하지 않는다 — 러너가 낸 가지를 볼지 합칠지는 사람이 정한다.
- 카드에 없는 일을 시작하지 않는다.
