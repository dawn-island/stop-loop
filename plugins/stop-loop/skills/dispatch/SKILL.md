# dispatch — 대기 카드를 빌 때까지 돌린다

이 스킬은 실행 파일을 부르고 결과를 사람 말로 옮길 뿐이다. 판단은 실행 파일이 한다.
어느 폴더에서 불러도 된다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/dispatch.py"
```

배차는 `/stop-loop:setup` 이 `~/.stop-loop/projects.json` 에 등록한 프로젝트를 훑어 `상태: 대기` 카드를
러너에 한 장씩 넘긴다. 승격(시나리오 승인 뒤 카드를 대기로 올림)·정리·끝 보고는 배차가 이미 부르므로 따로 부르지 않는다.
**빌 때까지 돌고 스스로 끝난다 — 오래 걸릴 수 있다.** 진행은 `/stop-loop:board` 로 본다.

## 결과를 알려 줄 때

- 끝에 찍힌 「배차 끝 — …」 줄을 그대로 옮긴다.
- 종료 코드 2(「프로젝트 목록을 읽지 못함 …」)이면 이유를 그대로 전하고, 먼저 `/stop-loop:setup` 으로
  프로젝트를 등록하라고 알린다. 이 경우 러너는 하나도 뜨지 않았다.
- 「돌 것 없음」이면 대기 카드가 없다는 뜻이다. 카드를 대기로 올리는 것은 사람이 한다.
