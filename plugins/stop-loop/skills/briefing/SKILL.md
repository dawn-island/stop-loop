# briefing — 오늘의 브리핑

이 스킬을 부른 세션이 이 프로젝트의 PM 이다. 프로젝트 뿌리에서 부른다. 읽기만 한다 —
카드를 고치거나 대기로 올리지 않고, 커밋하지 않는다. 러너·서브에이전트도 시작하지 않는다.
유일한 예외는 아래 「저장」 절이다. 인자로 날짜나 「어제」를 받았으면 새로 브리핑하지 않고 아래 「열기」 절만 따른다.
주민번호·계좌번호·비밀 값은 옮기지 않는다.

## 읽는 순서

1. **규칙 파일.** 이 세션에서 `docs/pm/규칙.md` 를 아직 읽지 않았으면 먼저 읽는다. 이미 읽었으면 다시 읽지 않는다.
   규칙 본문은 이 스킬에 싣지 않는다. 파일이 없으면 건너뛰고, 브리핑 맨 끝에 한 줄로 「규칙 파일이 없어 건너뜀」 이라고 알린다.
2. **보드.** 보드를 글로 찍는다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/board.py" .
```

   기한 지남·다시 확인·결과 빔의 날짜 비교와 개수는 보드가 찍은 그대로 쓰고 다시 계산하지 않는다.
   `--따라가기` 는 붙이지 않는다(백그라운드 프로세스를 남기지 않는다). 카드가 없으면 「없음」이라고 쓴다.
   보드가 실패하면 그 출력을 그대로 알리고 날짜 판단을 직접 하지 않는다. 그래도 아래 3번으로 이어 간다.
3. **git 상태.** 원격에서 뒤처졌는지(`git fetch` 뒤), 최근 커밋, 열린 워크트리(`git worktree list`),
   커밋 안 된 변경(`git status`)을 본다. `git fetch` 가 실패하면 「원격을 확인하지 못했다」 한 줄로 알리고 이어 간다.
4. **프로젝트별 문서.** 관문·기준선 일정처럼 프로젝트마다 다른 문서는 규칙이 가리키는 곳만 읽는다.
   규칙 파일이 없거나 아무것도 가리키지 않으면 읽지 않는다.

## 쓰는 것

고르는 기준은 위에서 아래 순서다: 기한이 지난 것 > 오늘 기한인 것 > 7일 안 관문을 막는 것 > 막는 것이 많은 것.

### 오늘 꼭 할 것

세 개. 하나마다 왜 오늘인지 한 줄을 붙인다.

### 다시 확인할 것

답을 기다리거나 확인일이 된 것과, 그 사람에게 보낼 짧은 독촉 문안.

### 진행 상황

보드의 진행·검토 칸과 최근 커밋에서 읽은 것만 쓴다.

### 계획과 달라진 것

계획 문서와 보드·git 이 어긋난 곳. 없으면 「없음」.

## 저장

켜는 법은 폴더다. `docs/pm/브리핑/` 이 있을 때만 저장하고, 없으면 저장하지 않고 지금처럼 읽기만 한다. 설정 키와 인자는 없다.
이 절이 「읽기만 한다」의 유일한 예외다. 브리핑을 다 쓴 뒤에 한다.

1. `docs/pm/브리핑/YYYY-MM-DD-HHMM.md` 로 쓴다(이 프로젝트가 쓰는 시간대). 시각이 붙으므로 두 PC 가 같은 날 써도 부딪히지 않는다.
   마지막 질문 줄은 넣지 않는다.
2. 현재 가지가 원격 기본 가지가 아니면 파일만 쓰고 커밋하지 않고 그렇다고 알린다.
3. 기본 가지이면 아래 순서로 한다. 끝의 `-- <파일>` 이 미리 올려 둔 다른 변경이 같이 들어가는 것을 막는다.

```bash
git add -- <파일>
git commit -m "브리핑: YYYY-MM-DD HH:MM" -- <파일>
git pull --no-rebase --no-edit
git push
```

4. 어느 하나가 실패하면 멈추고 「로컬 커밋까지 했고 push 하지 못했다」와 출력을 알린다. stash·reset·충돌 해결을 하지 않는다.

## 열기

인자가 날짜(`YYYY-MM-DD`) 또는 「어제」이면 새로 브리핑하지 않고 저장본을 연다. 읽기만 한다.

- 먼저 `git pull` 을 한다. 실패하면 `git fetch` 뒤 `git show origin/<기본 가지>:<경로>` 로 읽고 그렇다고 알린다.
- 그날 파일이 여럿이면 가장 늦은 것을, 없으면 있는 날짜 최근 다섯을 보인다. 저장된 브리핑이 없으면 「저장된 브리핑이 없다」고 알린다.
- 원격 주소가 GitHub 이면 맨 위에 파일 주소 한 줄을 쓴다(원격 주소에서 소유자와 저장소 이름을 정규식으로 읽는다). GitHub 이 아니면 저장소 안 경로만 보인다.
