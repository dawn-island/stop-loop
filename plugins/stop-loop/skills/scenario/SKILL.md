# scenario — 시나리오 작성

에이전트는 사람과 직접 대화하지 못한다. **대화는 이 세션이 하고, 에이전트는 살려 둔 채
이어서 말을 건다.** 이 스킬은 그 중계 절차다.

이 스킬을 쓰지 않아도 되는 때가 있다. 무엇을 할지 이미 아는 일이면 `docs/backlog/` 에
이슈를 바로 쓴다 — 시나리오를 쓰는 값이 더 크다(hq 기록 38).

## 1. 대화를 파일로 남긴다

에이전트는 이 대화를 볼 수 없다. 먼저 사람의 말을 **원문 그대로** 적는다. 요약하지 않는다.

```
docs/plan/_대화/<날짜>-<주제>.md
```

형식은 「사람: …」과 「나: …」 줄의 나열이면 된다. 덧붙이기만 하고 지우지 않는다 —
회차가 돌 때 에이전트가 이 파일의 뒤쪽을 다시 읽는다.

등록 자료(명세·화면·수출본)는 경로만 모아 이 파일 머리에 적는다.

## 2. 에이전트를 띄운다

Agent 도구로 `loop-scenario` 를 부른다. 위임문에는 경로만 넣는다.

- 대화 기록 경로
- 등록 자료 경로들
- 산출물 자리: `docs/plan/` 와 틀 — 틀 위치는 이 스킬이 사는 자리에 따라 다르다
  - hq: `workflows/stop-loop/templates/SC-scenario.template.md`
  - 꾸러미를 푼 프로젝트: `.stop-loop/workflows/stop-loop/templates/SC-scenario.template.md`
  - 플러그인: `${CLAUDE_PLUGIN_ROOT}/workflows/stop-loop/templates/SC-scenario.template.md`

**이 에이전트를 죽이지 않는다.** 회차를 돌 때 같은 에이전트에게 말을 걸어야 맥락이
이어지고, 다시 읽는 값이 들지 않는다.

## 3. 결과를 사람에게 보인다

시나리오 파일을 읽고 사람에게 이 순서로 전한다.

1. 시나리오 목록과 각 요소 — 「사람이 하면 몇 분」과 선행 관계까지
2. 「확인 필요」에 올라온 질문 — 이것이 사람이 답할 차례다
3. 요소별 주요 기능이 구체적인지 — 규칙·예외·다루는 값이 비어 있으면 그 자리를 짚는다
4. 요소마다의 카드 초안 목록 — 경로·담는 요소·밝힌 되돌리기 어려운 변경
5. 승인 전 점검 결과와 걸린 것의 처리 — 시나리오의 「승인 전 점검」 절을 읽어 전한다

## 4. 회차를 돈다

사람의 답과 지적을 **대화 기록 파일에 덧붙인 뒤**, 같은 에이전트에게 SendMessage 로
「기록의 어디부터 읽고 반영하라」고 전한다.

지켜야 할 것이 셋이다.
- 식별자(`SC-`·`AC-`·`E-`·`F-`)는 그대로 둔다. 번호가 밀리면 그것을 인용한 이슈가 깨진다.
- 없어진 것은 지우지 않고 「없어짐 — 이유」로 남긴다.
- 회차마다 「변경 이력」에 한 줄이 늘어야 한다. 안 늘었으면 반영이 안 된 것이다.

## 5. 확정하고 넘긴다

사람이 됐다고 하면 시나리오의 `상태` 를 「확정」으로 바꾸게 하고, `docs/plan/README.md`
목록을 맞춘다.

**승인은 시나리오와 초안을 함께 한다.** 배차(`bin/dispatch.py`)가 있는 프로젝트(hq 처럼)에서는
상태를 「확정」으로 바꾸면 배차가 다음 훑기에 승인을 판정한다. 「확인 필요」가 비어 있고 `(카드 아님)` 으로
표시한 요소를 뺀 요소가 모두 카드에 담겼으면 선행 없는 카드를 대기로 올리고 시나리오를 「구현 중」으로
바꾼다 — 앞선 카드가 병합되어 완료되면 다음 카드가 이어서 오른다. 거부되면 배차 출력에 「승인 거부 —
프로젝트/SC-nn: 까닭」이 나온다. **승인한 뒤 고칠 때는 상태를 「초안」으로 내렸다가 고친 다음
「확정」으로 다시 올린다**(다시 승인, 사람 손으로 한 번 센다) — 구현 중 그대로 고치면 장치가 알아보지 못한다.
배차가 없는 프로젝트에서는 사람이 카드를 대기로 올린다. 초안은 승인 전까지 아이디어 상태로 남는다
(hq 에서 승인 절차는 E-2 이고, 시나리오에 묶이지 않은 카드는 hq `CLAUDE.md` 5절 대로 사람이 올린다).
에이전트가 초안을 쓸 때 지키는 기준은 셋이다(hq 기록 38).
- 요소가 **관찰되는 동작**인가. 계층 조각이면 초안이 아니다
- 「사람이 하면 30분 미만」이면 이웃 요소와 묶는다
- 선행 관계대로 순서를 정하고, 그 순서로만 대기에 올린다

초안에는 완료 기준 `AC-n` 을 카드 틀(`docs/backlog/_템플릿.md`)이 정한 절로 그대로 옮긴다. 옮기면서
문장을 바꾸지 않는다 — 바꾸면 시나리오와 초안이 갈린다.
