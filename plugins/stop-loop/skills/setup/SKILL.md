# setup — 프로젝트를 세우고 표준 구간을 올린다

이 스킬은 실행 파일을 부르고 결과를 사람 말로 옮길 뿐이다. 판단은 실행 파일이 한다.
프로젝트 뿌리에서 부른다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/setup_project.py" .
```

실행 파일은 `CLAUDE.md` 가 없으면 새 프로젝트 틀로 만들고, 있으면 표시 구간만 바꾼다(구간 바깥은 그대로다).
`stop-loop.config.json` 과 `docs/backlog/_템플릿.md` 는 없을 때만 만들고, `.claude/settings.json` 에는 다른 열쇠를
지킨 채 이 플러그인 정의만 더한다.

## 결과를 알려 줄 때

- 찍힌 「생성 …」·「갱신 …」 줄을 그대로 목록으로 옮긴다. 「바꾼 파일 없음」이면 그렇게 말한다.
- 「등록 …」 줄이 있으면 이 기계의 배차(`/stop-loop:dispatch`)가 이제 이 프로젝트를 훑는다고 알린다.
- 「남은 사본 …」 줄이 있으면 사람에게 알린다. `.claude/agents/` 의 옛 사본이 플러그인 새 판보다 먼저 읽혀
  새 판이 무시된다. 이 스킬은 사본을 지우지 않는다 — 지울지는 사람이 정한다.
- 이 스킬은 커밋하지 않는다. 바뀐 것은 `git status` 로 확인하고 커밋은 사람이 한다.
- 새로 만든 `CLAUDE.md` 의 `<프로젝트 이름>` 같은 자리표시는 채우지 않았다고 말해 준다.
- 실패하면(`실패: …`) 이유를 그대로 전한다. 이 경우 아무 파일도 바뀌지 않았다.
