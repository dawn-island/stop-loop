# board — 진행을 한눈에 본다

이 스킬은 실행 파일을 부르고 결과를 사람 말로 옮길 뿐이다. 프로젝트 뿌리에서 부른다.

1. 칸을 찍어 그대로 옮긴다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/board.py" .
```

2. 이어 같은 명령에 `--따라가기` 를 붙여 부르고, 찍힌 주소 한 줄을 알린다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/board.py" . --따라가기
```

- 이 기기에 보드가 이미 떠 있으면 새 서버를 띄우지 않고 그 프로젝트 주소 한 줄만 찍고 끝난다 — 그대로 알린다.
- 떠 있는 보드가 없으면 모든 프로젝트를 보는 서버 하나를 띄운다. 끝나지 않는 명령이므로 **백그라운드로** 띄우고(대화가 막히지 않게) 프로세스 번호를 함께 알려 사람이 끌 수 있게 한다.
- 고정 자리 `127.0.0.1:8700` 을 다른 프로그램이 쓰고 있으면 그 사실과 쓰는 프로그램이 찍힌다 — 그대로 알린다. 다른 번호로 옮겨 띄우지 않는다.
- 「보는 목록에 없다」가 함께 찍히면 그대로 알린다 — 보기 목록에 올려야 홈에 보인다.

로그인 때마다 보드가 저절로 떠 있게 하려면 한 번만 켠다(끄려면 `--상주-끄기`) — 이 사실을 한 번 알린다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/board.py" --상주-켜기
```

보드가 쓰는 곳은 이 기기의 보드 전용 자리 셋(`~/.stop-loop/mirrors/` 거울, `~/.stop-loop/board-cache/` 원격 그림, `~/.stop-loop/human-resolved/` 사람 손 기록)과 사람이 누른 단추 셋(「카드로 만들기」·「카드에 잇기」·「대기로 올리기」 — 아이디어 카드 파일을 쓰고 원격에 올린다)이다. 상주 보드는 프로젝트 작업 사본을 스스로 바꾸지 않고, 카드 상태는 원격(거울)에서 읽는다. 단추는 이 기기(127.0.0.1)에서 보드 화면이 보낸 요청만 받는다.
