# board — 진행을 한눈에 본다

이 스킬은 실행 파일을 부르고 결과를 사람 말로 옮길 뿐이다. 프로젝트 뿌리에서 부른다.

1. 칸을 찍어 그대로 옮긴다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/board.py" .
```

2. 이어 같은 명령에 `--따라가기` 를 붙여 **백그라운드로** 띄우고(대화가 막히지 않게), 찍힌 주소를 알린다:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/board.py" . --따라가기
```

보드는 읽기 전용이라 카드를 바꾸지 않는다. 따라가기는 그 프로세스를 끝내면 멈춘다 —
백그라운드로 띄웠으므로 사람이 Ctrl-C 를 누를 자리가 없다. 프로세스 번호를 함께 알려 주어 사람이 끌 수 있게 한다.
